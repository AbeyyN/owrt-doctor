# Maintainer Metrics

Do not manufacture stars, downloads, issues or contributors.

Track real evidence:

| Signal | Evidence |
|---|---|
| Stars/forks | GitHub repository insights |
| Release downloads | GitHub release asset download counts |
| Unique cloners | GitHub traffic insights |
| Issues | Real user bug reports / requests |
| PRs | External contributions and reviews |
| Releases | Tagged releases + changelog |
| Package installs | Feed/download metrics when available |
| Ecosystem impact | Upstream references, package inclusion, integrations |

For maintainer-support programs, truthful evidence of real maintenance responsibility matters more than vanity metrics.
