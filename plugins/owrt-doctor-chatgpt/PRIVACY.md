# OWRT Doctor Plugin Privacy Notice

Version: 0.1.0

OWRT Doctor v0.1 processes only diagnostic content explicitly supplied to its MCP tools. This may include router model/hostname, interface and route state, IP addressing, DNS servers, DHCP metadata, Wi-Fi metadata and recent network logs.

The plugin does not connect directly to a user's router and does not perform router configuration changes.

Do not submit passwords, Wi-Fi PSKs, API tokens, cookies, private keys or other credentials. The plugin applies limited redaction to common credential-shaped fields before rule-based analysis, but arbitrary diagnostic text cannot be guaranteed to be free of secrets.

Before public launch, this repository notice must be mirrored to the final public privacy-policy URL together with production hosting, retention, logging, contact and deletion details.
